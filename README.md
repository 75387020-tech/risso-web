# Risso

Sitio estático de Industrias Risso (HTML, CSS y JavaScript). Listo para GitHub Pages.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub y sube esta carpeta.
2. En el repositorio: **Settings → Pages**.
3. En **Source** elige **Deploy from a branch**.
4. Branch: `main` (o `master`) y carpeta `/ (root)`.
5. Guarda. La web quedará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

Si el repositorio se llama `TU-USUARIO.github.io`, la web se publica en la raíz de tu usuario.
